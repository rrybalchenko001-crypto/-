# Лабораторная работа №10. Текстовые файлы и обработка ошибок

Готовое решение на Python. **Индивидуальный вариант: 1** — сумма положительных элементов матрицы.

## Состав папки

- `main.py` — главная программа, безопасный ввод положительного целого числа и создание отчёта.
- `files_lab.py` — чтение матрицы UTF-8 и проверка формата файла.
- `table.py` — суммы строк и столбцов.
- `variant.py` — вычисление индивидуального задания.
- `matrix.txt` — входные данные из примера задания.
- `report.txt` — пример сформированного отчёта.
- `test_files.py` — автоматические проверки, включая ошибочные входные файлы.

## Запуск

Нужен Python 3.10 или новее. Откройте терминал в этой папке и выполните:

```bash
python main.py
```

Программа прочитает `matrix.txt`, проверит все данные и только затем создаст/перезапишет `report.txt`. При ошибке файл отчёта не перезаписывается.

## Формат `matrix.txt`

Первая строка содержит два положительных целых числа: количество строк и столбцов. Далее должны идти ровно указанное количество строк, в каждой — ровно указанное количество целых чисел.

Пример:

```text
2 3
1 -2 3
4 0 -6
```

## Проверка

Запустите:

```bash
python -m unittest -v
```

## Пример результата

```text
Суммы строк: 2 -2
Суммы столбцов: 5 -2 -3
Результат варианта 1: 8
```

`read_positive_integer()` повторяет запрос при нечисловом вводе или числе, которое не больше нуля. `read_matrix()` сообщает тип проблемы и номер строки, где это возможно.
