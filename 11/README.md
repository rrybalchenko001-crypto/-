# Лабораторная работа №11. JSON и получение данных по HTTP

Решение выполнено простыми средствами Python, без сторонних библиотек.

**Индивидуальный вариант принят как вариант 1:** выбрать все задачи указанного пользователя. Если у тебя другой номер варианта, напиши его — условие в `select_tasks()` нужно будет поменять.

## Файлы

- `todos.json` — учебный набор задач.
- `analysis.py` — проверка JSON, подсчёт выполненных задач, поиск лидеров и выбор задач пользователя.
- `main.py` — локальная обработка JSON и сохранение `leaders.json`.
- `fetch_profile.py` — запрос публичного профиля GitHub по HTTP и сохранение `profile.json`.
- `profile_sample.json` — пример профиля для работы без интернета.
- `test_analysis.py` — автоматические проверки.

## Запуск

Локальная часть:

```bash
python main.py
```

HTTP-упражнение (нужен интернет):

```bash
python fetch_profile.py
```

Проверки:

```bash
python -m unittest -v
```

## Что делает программа

1. Открывает `todos.json` в кодировке UTF-8 и читает его через `json.load()`.
2. Проверяет, что корень — список, `id` и `userId` — положительные целые числа, `title` — непустая строка, `completed` — именно `True` или `False`.
3. Считает выполненные задачи отдельно для каждого пользователя.
4. Находит всех лидеров, включая несколько пользователей при равенстве результата, и сохраняет их ID в `leaders.json`.
5. Спрашивает `user_id` и показывает все задачи этого пользователя. Для неизвестного ID выводится пустой список.
6. Отдельный файл `fetch_profile.py` получает профиль GitHub. При HTTP 404, 403, ошибке сети или неверном JSON выводит понятное сообщение.

## Пример для учебного набора

У пользователей 5 и 10 по две выполненные задачи, поэтому оба попадут в `leaders.json`:

```json
[
  5,
  10
]
```
