# Лабораторная работа: двумерные списки и рекурсия

## Файлы

- `table.py` — функции для матриц.
- `main.py` — основная программа.
- `test_table.py` — проверки с помощью assert.
- `recursion.py` — дополнительное задание с факториалом.

## Запуск

Откройте папку проекта в PyCharm. В терминале выполните:

```bash
python test_table.py
python main.py
python recursion.py
```

## Что делает программа

1. Считывает количество строк и столбцов.
2. Считывает матрицу. Проверяет, что в каждой строке введено нужное количество чисел.
3. Вычисляет суммы строк и столбцов.
4. Создаёт диагональный узор заданного положительного размера.
5. Выполняет преобразование матрицы по выбранному варианту от 1 до 15.
6. Показывает новую матрицу и исходную матрицу.

## Краткая теория

**Матрица** — это список, внутри которого находятся другие списки. Например:

```python
matrix = [[1, 2, 3], [4, 5, 6]]
```

В матрице два ряда и три столбца. `matrix[0][1]` — это элемент первой строки и второго столбца, то есть 2.

**Цикл for** повторяет команды для каждого элемента или значения.

**Условие if** проверяет условие и выполняет команды, если оно истинно.

**Функция** — именованный блок команд. `return` возвращает результат функции.

**assert** проверяет правильность результата. Если результат не совпал с ожидаемым, тест выдаёт ошибку.

## Важные моменты

- `row_sums` проходит по строкам и складывает их элементы.
- `column_sums` берёт каждый номер столбца и складывает элементы с этим номером во всех строках.
- `diagonal_pattern` сравнивает номера строки и столбца: равны — 0, строка выше — 1, ниже — 2.
- `transform` создаёт новую матрицу. Исходная матрица не меняется.
- Вариант 11 использует `//` — целочисленное деление.
- В варианте 14 границы -2 и 3 включаются.
- В варианте 15 положительные числа заменяются на 1, отрицательные на -1, нули остаются нулями.

## Ответы для защиты

**Что такое двумерный список?**  
Это список, в котором каждый элемент является другим списком.

**Как обратиться к элементу матрицы?**  
Например, `matrix[1][2]`: сначала указывается номер строки, затем номер столбца. Счёт начинается с нуля.

**Как программа считает суммы строк?**  
Берёт строку и использует `sum`, затем добавляет сумму в результирующий список.

**Как программа считает суммы столбцов?**  
Проходит по номерам столбцов. Для каждого номера складывает элементы с этим индексом во всех строках.

**Почему матрица не меняется после преобразования?**  
Потому что функция создаёт новый список и новые строки, а исходные элементы не перезаписывает.

**Что такое рекурсия?**  
Это когда функция вызывает саму себя.

**Что такое факториал?**  
Это произведение натуральных чисел от 1 до заданного числа. Например, 5! = 5 × 4 × 3 × 2 × 1 = 120. По определению 0! = 1.

**Зачем нужен базовый случай?**  
Чтобы остановить рекурсивные вызовы. В нашей функции это `if number == 0`.

## Дополнительное задание

Функция `factorial` вызывает сама себя с числом на единицу меньше. Например, для 3 вызовы идут так: 3, 2, 1, 0. При нуле функция возвращает 1. Затем результаты перемножаются: 1 × 1 × 2 × 3 = 6.
